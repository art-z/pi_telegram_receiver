# STT Telegram Relay Service

Сервис принимает распознанные STT-сообщения по HTTP и пересылает их в Telegram.

Основной сценарий: Raspberry Pi или другой клиент распознаёт речь, собирает текстовые фразы и отправляет их на этот сервис. Сервис форматирует сообщение и отправляет его в указанный Telegram-чат через бота.

## Что делает сервис

- принимает входящие HTTP-запросы с текстом;
- обрабатывает STT-события;
- формирует текстовое сообщение;
- отправляет сообщение в Telegram;
- может использоваться как промежуточный relay между устройством распознавания речи и Telegram.

## Переменные окружения

Создайте файл `.env` рядом с `docker-compose.yml`:

```env
INCOMING_TOKEN=CHANGE_ME_SECRET_TOKEN
TELEGRAM_BOT_TOKEN=your_telegram_bot_token
TELEGRAM_CHAT_ID=your_telegram_chat_id
```
Сервис на текущем этапе не валидирует INCOMING_TOKEN.
